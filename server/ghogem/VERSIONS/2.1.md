# GhoGem 2.1 — Version Notebook

Статус: in development
Дата начала записи: 2026-09-30

## Главная фишка
- Same-card follow-up: пользователь может дописать/уточнить запрос во время активной генерации, а GhoGem продолжает ту же задачу и ту же карточку вместо запуска отдельного ответа.

## Added
- AI-помощник по очистке хранилища с подтверждением каждого удаления.
- История использования файлов: last_used_at, last_used_chat_id, use_count.
- Массовая очистка хранилища.
- Расширенные расписания напоминаний.
- Напоминания общие между чатами пользователя.
- `recent_reminders` — последние реально сработавшие напоминания.
- `🧠 Забыть ответ` — удаление конкретного assistant-ответа из будущего AI-контекста без удаления Telegram-сообщения.
- Избранные модели.
- Модель по умолчанию для новых чатов.
- Раздел настроек.
- Извлечение аудиодорожки из видео (`extract_audio`).
- Настройка часового пояса пользователя; новые задания сохраняют свой timezone и recurring-расписания учитывают DST.

## Changed
- Переработан agent streaming / «Ход работы»: компактнее, хронологично, без утечек служебного reasoning/tool-текста.
- Сработавшие напоминания сохраняются как события истории чата и могут учитываться в дальнейшем разговоре.
- Планировщик напоминаний переведён на event-driven схему: в RAM хранится только ближайший task_id + due_at; полная карточка читается из SQLite при срабатывании.
- Тяжёлые media-операции выполняются через очередь с одним одновременным worker на текущем 1-vCPU сервере.

## Security
- Усилены проверки destructive actions и владельца ресурсов.
- AI-cleanup не удаляет файл без Telegram-подтверждения пользователя.
- Фоновые AI-задания получают серверно ограниченный набор side-effect tools; внешняя страница не может расширить их права через prompt injection.
- Удаление файлов, cleanup storage, изменение и пропуск напоминаний запрещены фоновой задаче без нового живого подтверждения.

## Pending / не считать готовым релизом
- Web App V2 ещё не завершён и не должен рекламироваться как законченная функция 2.1.

## Не новое в 2.1
- Tool calling, базовая работа с файлами, память, web search, image analysis, STT/TTS и большой каталог моделей существовали раньше и не должны называться новыми фичами 2.1.

# GhoGem Version Notebook

Эта папка — постоянная версионная записная книжка проекта.

Для каждой версии создаётся отдельный файл `X.Y.md` и он обновляется по мере разработки, а не задним числом.

В каждой записи фиксируются только подтверждённые изменения:
- Added — новое
- Changed — изменённое поведение
- Fixed — исправления
- Security — права, подтверждения, защита
- Internal — архитектура, БД, очереди, миграции
- Pending — начато, но ещё не закончено и не должно попадать в релиз как готовое

Правило: не приписывать версии функции, которые существовали раньше. Перед финальным релизным постом запись сверяется с кодом и тестами.

# GhostMine — спецификация (клон MineEnergy 2)

Снято напрямую с живой игры **mineenergy2.fun** (аккаунт waki) 2026-06-23.
Цель: воспроизвести оригинал «ПРЯМО как есть» по виду и механикам.
Валюта в нашей версии: оставляем `$` как в оригинале (деньги), плюс энергия `⚡`.

---

## 1. Вид и мир
- **Top-down, лёгкий 2.5D**, Minecraft-пиксель-арт. Блоки с небольшой «высотой»/тенью.
- Трава (зелёная, **темнеет ночью**), под землёй — дёрт (коричневый), **лава** (оранжевая), **вода** (синяя), руда (серые каменные блоки с цветными вкраплениями).
- Большой исследуемый мир, координаты **X / Y / Z** в правом верхнем углу.
- Декор: кустики травы, деревья, дропнутые предметы (кирки, птицы).

## 2. Окружение (симуляция)
- **День/ночь** — часы (быстрый цикл). Луна/солнце в инфо-баре.
- **Ветер** — скорость в м/с (инфо-бар). Влияет на ветрогенератор (макс при 24 м/с, **ночью меньше**).
- **Температура** — °C (инфо-бар). Влияет на ядерный реактор (**перегрев > 21°**).
- **Биомы**: пустыня (бонус солнечным), север/холод (бонус ядерному). Обычный/лес.
- **Соседние блоки**: лава (геотермальный), вода (водяная турбина).

## 3. Игрок
- Пиксель-персонаж (мордочка-панда), в руке — экипированный инструмент.
- **Здоровье**: 9–10 сердец.
- **Хотбар 1–5** (инструменты/блоки для установки).
- **Копка**: зажать/клик → прогресс **%** у курсора.
- Движение WASD, ЛКМ — копать/бить/ставить.

## 4. Ресурсы (HUD справа-внизу, у каждого скорость «/т» = в тик)
Порядок: **$ деньги** · **⚡ энергия** · **железо** · **уран** · **алмаз** · **золото** · **иридий** · **уголь**.
Плюс для крафта/ремонта: **камень** (cobblestone), **нефть** (для нефтяного генератора).
Тиры руды по глубине/кирке: уголь → железо → золото → алмаз → уран → иридий.

## 5. Магазин — 7 вкладок

| Кирка | Добывает (в удар) | Урон | Цена |
|---|---|---|---|
| Деревянная | уголь+1, железо+1 | 1♥ | 50 угля |
| Железная | +2 уголь/железо, +1 золото | 1♥ | 100 угля |
| Золотая | +3 уголь/железо, +2 золото, +1 алмаз | 1♥ | 200 золота + $1K |
| Алмазная | +4 уголь/железо, +3 золото, +2 алмаз, +1 уран | 2♥ | 300 алмазов + $2K |
Кирка тира открывает добычу следующей руды. «Алмазная не требует энергии».

### Вкладка 2 — Мечи (оружие)
4 тира: урон **2 / 3 / 5 / 7** ♥ за $500 / $10K / $50K / $100K.
**Нано-сабля**: урон 10♥, **−25⚡ за удар**, ваншот незащищённой цели. $500K.

## 6. Экономический цикл
Копать руду (кирка) → купить **генераторы** (энергия) → **добытчики** (авто-добыча, едят энергию) →
**продавцы** (энергия/ресурс → деньги) → лучшее снаряжение/оборона → расширение базы.
Всё надо **чинить** (ремонт тратит ресурсы каждый тик).

## 7. Бой / рейд
- **Мобы**: зомби (PvE) ходят к базе/игроку.
- **PvP**: другие игроки рейдят базы. Тесла авто-защищает (зап в радиусе 6). Стены/двери держат.
  Рейдер ломает вход киркой/мечом/Теслой.
- **Кровать** — точка респавна; ломают кровать → теряешь точку (то, что выбесило в оригинале).
- Броня снижает урон %, лучший меч убивает быстрее.
- **Команды** ([team], [dog]), лидерборд по деньгам, чат.

## 8. HUD (точная раскладка)
- **Сверху-слева**: «Топ игроков» — ранг, ник, $.
- **Сверху-центр**: 3 кнопки (**магазин · инвентарь · команды**) + ниже бар: часы(день/ночь) · ветер(м/с) · темп(°).
- **Сверху-справа**: X / Y / Z.
- **Снизу-центр**: ряд сердец + хотбар 1–5 + индикатор копки «%».
- **Снизу-слева**: чат («Сообщение», «Нажмите … для чата»).
- **Снизу-справа**: ресурсы (иконка · кол-во · «/т» скорость).
Шрифт — пиксельный, белый, значения цветные.

## 10. Доп. механики (снято с живой игры, 2-й проход)

### Инвентарь (кнопка-рюкзак сверху-центр)
- Слева: **слот брони/экипировки** (надетая броня) + кнопка **«снять»** (eject).
- Сетка **5×3 = 15 слотов**. Кирка лежит предметом.
- Предметы перетаскиваются мышью; **ПКМ — разделить стак**.
- **Крафта нет** — всё через магазин. Хотбар 1–5 = быстрый доступ к предметам/блокам.

### Смерть и респавн
- Экран «**Игра закончена / Вы погибли / Вы можете переродиться!**» + кнопки «Discord» и «**Переродиться**».
- При смерти **теряешь предметы/ресурсы** (хотбар сбрасывается до базовой кирки; деньги остаются $1K-минимум? уточнить).
- После респавна — **спавн-защита «Бессмертие»: бессмертен 1 минуту ИЛИ до первой своей атаки** (поп-ап «Хорошо»).

### Персонаж (точный вид)
- Minecraft-стайл сверху: **загорелая квадратная голова, два зелёных глаза**, светло-серое тело (рубашка), в руке — экипированный инструмент торчит вбок. НЕ панда.

### Карта/мир
- **Финитная карта** с краями: за границей — синий горизонт/«океан». Лёгкая псевдо-3D перспектива (даль выше и мельче).
- Биомы полосами: трава (равнина), дёрт/камень (горы/пещеры — много руды), пустыня, снег/север.
- Декор: **ромашки/васильки** (белые/синие цветы), кустики травы, лужи воды, лава.

### Команды (3-я кнопка сверху — корона)
- **Создать команду**: поля **Имя** + **Слоган**. Слоган = тег `[dog]`, `[team]` перед ником.
- Механика: «**если товарищ выйдет из игры или погибнет — его блоки переходят другому товарищу**» (если у нового владельца не превышены **лимиты блоков**). → база живёт внутри тимы.
- Список **«Другие команды»** с кнопкой **Присоединиться** (напр. `dog` / «bark bark»).
- У каждого игрока **лимит на количество блоков/построек** (важно для баланса базы).

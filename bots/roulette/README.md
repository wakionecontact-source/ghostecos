# OKey — бот для знакомств

Чистый aiogram 3, один файл, SQLite. Без админ-панелей и FastAPI рядом.

## Что есть сейчас

- `/start` — приветствие, главное меню внизу
- **Анкета** через FSM-wizard: имя → возраст → пол → ищу → био → фото
- **«👤 Моя анкета»** — посмотреть, кнопкой «Изменить» — заполнить заново
- **Главное меню** (reply-клавиатура внизу) всегда видно

## Что **будет**

- 🔍 Поиск — смотреть анкеты других, лайки, match-уведомления
- 🎲 Рулетка — случайный собеседник
- 🔗 Привязка к GhostEcos-аккаунту
- Жалобы и бан

## Запуск (Windows)

1. Python 3.10+ с [python.org](https://python.org), галка «Add to PATH»
2. V2RayTun в TUN-режиме (или другой VPN захватывающий весь трафик)
3. Токен у @BotFather
4. Двойной клик `start.bat`
5. Откроется блокнот с `.env` — впиши `BOT_TOKEN`
6. Сохрани, запусти `start.bat` ещё раз

В консоли увидишь:
```
БД: ...\okey.db
Бот @ТвойБот (id=...)
Polling запущен. Жди /start от себя в боте...
```

## Структура

```
bot.py            # всё здесь — handlers, БД, FSM, polling
start.bat
requirements.txt
.env.example
okey.db           # SQLite, создаётся при первом запуске
```

## Если /start не отвечает

1. Посмотри в окно cmd — есть ли строки `[update]`? Если нет — Telegram не присылает updates. Скорее всего был установлен webhook (от LiveGram, @ManyBot и т.п.). Бот сам сбросит при следующем старте.
2. Сообщение `Не могу подключиться к Telegram` — VPN не работает или токен битый.
3. Если бот падает на старте — пришли последние 20 строк лога.

# Как управлять подписками

## 1. Стать админом

В `.env` впишите свой Telegram `user_id` в `ADMIN_USER_ID`. Узнать свой id
можно у `@userinfobot` — просто напишите ему, он пришлёт ваш числовой id.

Пока `ADMIN_USER_ID` не задан (или равен 0), админ-команды никому не
отвечают — это осознанно, чтобы посторонний, угадавший команду, не увидел
даже намёка на её существование.

## 2. Админ-команды (доступны только вам)

- `/grant <user_id> <дней>` — выдать подписку любому пользователю на N дней.
  Пример: `/grant 123456789 30` — выдать на 30 дней. Полезно, если кто-то
  заплатил вам вручную (перевод другу, договорились в личке и т.п.) — вы
  просто выдаёте подписку сами, без реальной оплаты через бота.
- `/revoke <user_id>` — немедленно забрать подписку у пользователя
  (например, если оплата была спорной или отменена).
- `/subscribers` — список всех, у кого сейчас активна подписка, и до какой
  даты.

Эти команды не показываются в меню бота (специально) — работают, только
если написать их текстом, и только с вашего аккаунта.

## 3. Как приходят деньги

### Telegram Stars (основной способ)
Оплата идёт через встроенную валюту Telegram — никакого юридического лица
или банковского счёта заводить не нужно. Когда пользователь платит:
1. Бот создаёт ссылку на оплату (`create_invoice_link`)
2. Пользователь платит звёздами внутри Telegram
3. Боту приходит `successful_payment`, он сам продлевает подписку в базе
4. Через 30 дней Telegram **сам** списывает звёзды повторно (автопродление) —
   с вашей стороны ничего делать не нужно, просто снова придёт
   `successful_payment`

**Как забрать деньги себе**: звёзды копятся на балансе бота внутри
Telegram. Вывести их в деньги можно через **Fragment**
(https://fragment.com) — это официальный сервис Telegram для обмена Stars
на TON. Зайдите в `@BotFather` → выберите бота → там будет пункт про баланс
звёзд и вывод.

**Если нужно вернуть деньги пользователю** (спор, ошибка): у Telegram есть
метод `refundStarPayment` (принимает `user_id` и `telegram_payment_charge_id`
из полученного `successful_payment`) — в текущем боте отдельной команды для
возврата нет, при необходимости попросите добавить.

### CryptoBot (оплата криптой, если настроен `CRYPTO_BOT_TOKEN`)
1. Бот создаёт счёт через API `@CryptoBot`
2. Пользователь платит и жмёт «Проверить оплату»
3. Бот спрашивает статус у CryptoBot и, если оплачено, продлевает подписку

**Важно**: это опрос по кнопке, а не автоматическое уведомление — если
пользователь заплатит и не нажмёт кнопку, бот не узнает об этом сам. Если
захотите на это надёжный вебхук — CryptoBot его поддерживает, но текущая
версия бота его не использует.

**Как вывести деньги**: баланс USDT/TON и вывод — прямо в `@CryptoBot` →
раздел с балансом приложения → Withdraw.

## 4. Где хранятся подписки

Файл `subscriptions.db` рядом с `bot.py` (SQLite). При переносе бота на
другой сервер скопируйте и его — иначе все подписки обнулятся. Стоит
время от времени делать его резервную копию (просто скопировать файл).

## 5. Быстрая проверка, что всё работает

1. Отправьте себе `/grant <ваш_id> 1` — должна прийти подписка на 1 день
2. `/status` должен показать «Подписка: активна до ...»
3. `/model` — премиум-модели должны быть без замка 🔒
4. `/revoke <ваш_id>` — подписка должна исчезнуть, модели снова закрыты

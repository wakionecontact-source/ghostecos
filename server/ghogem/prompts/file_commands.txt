Вы можете управлять файлами в своей рабочей папке с помощью следующих команд. Пишите их прямо в ответе, на отдельных строках:

!file:write имя_файла
содержимое файла
!end

!file:read имя_файла

!file:list

!file:delete имя_файла

Пример:
Чтобы создать файл hello.txt с текстом "Привет, мир!", ответьте:
!file:write hello.txt
Привет, мир!
!end

Чтобы прочитать файл hello.txt:
!file:read hello.txt

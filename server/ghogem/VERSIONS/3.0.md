# GhoGem 3.0 — Version Notebook

Статус: active development
Обновлено: 2026-10-06

## Главная тема
GhoGem 3.0 посвящён только сравнению и оценке моделей:
- оценки ответов;
- Arena;
- рейтинг моделей;
- карточки моделей;
- каталог и фильтры;
- статистика, необходимая именно для рейтинга и карточек.

## Scope freeze
В 3.0 НЕ входят:
- Work Mode;
- multi-agent;
- sandbox mini-apps;
- public chat;
- GhostAsk;
- новый большой agent core;
- новая система памяти;
- большой новый web-search;
- прочие крупные функции, не связанные напрямую с моделями и рейтингом.

Они переносятся в 4.0+ или отдельные обновления.
Критические исправления текущего GhoGem разрешены.

## Порядок разработки
1. Сначала сайт.
2. Затем backend Arena / ranking.
3. Затем интеграция с Telegram-ботом.
4. Выпуск 3.0 сразу после готовности основных функций — без бесконечного расширения scope.

## Сайт 3.0
Основные разделы:
- Рейтинг
- Арена
- Модели

### Рейтинг
- общий рейтинг моделей;
- фильтры Free / Premium / мультимодальные;
- реальные оценки пользователей;
- число оценок;
- позже: категории и Arena rating;
- никаких выдуманных показателей.

### Арена
- один запрос отправляется двум моделям;
- названия моделей скрыты до голосования;
- варианты: A / B / ничья;
- после голоса модели раскрываются;
- матч записывается в историю рейтинга;
- интерфейс сайта делается раньше движка Arena.

### Карточки моделей
Карточка должна уметь показывать:
- название;
- разработчика;
- размер / active params;
- Free / Premium;
- мультимодальность;
- провайдера / маршруты;
- доступность;
- среднюю оценку;
- число оценок;
- позже: Arena wins/losses/draws, место и категории.

## Модели и провайдеры
Одна логическая модель в будущем может объединять несколько provider routes.
Исторические записи нельзя удалять из базы/реестра, если с ними связаны оценки.

### Статусы
Поддерживаем минимум:
- работает;
- временно недоступна;
- проблемы провайдера / статус неизвестен;
- free-версия отключена;
- удалена/retired.

Примеры на 2026-10-05:
- Space Bunny Alpha: видима, но недоступна; проблемы провайдера, endpoints отсутствуют.
- GLM 5.2 Free: запись сохранена ради истории и оценок, но скрыта из каталога и fallback.

## Оценки
Текущая система 1–5 сохраняется и становится источником реальных пользовательских данных.
Нужно развить:
- average;
- votes;
- distribution 1–5;
- история;
- разделение логической модели и provider route там, где это понадобится.

## Release gate
3.0 можно выпускать, когда готовы:
- сайт с рейтингом;
- реальные карточки моделей;
- рабочая Arena;
- рейтинг на данных оценок/Arena;
- базовые фильтры и статусы.

Всё остальное переносится дальше, даже если идея хорошая.

## 2026-10-06 — начальный глобальный рейтинг
- Добавлен `GET /ratings/ranking` и страница «Рейтинг» в веб-интерфейсе.
- Источник — текущая сохранённая оценка каждого ответа из `model_responses`, как в существующих агрегатах `/ratings/model`; повторное изменение оценки не считается новым голосом.
- Сортировка по среднему баллу, затем по числу оценок. Используются только реальные оценки, без сглаживания и искусственных весов.
- Показываются число оценок, распределение 1–5, статусы моделей и фильтры Free / Premium / мультимодальные.
- В рейтинг попадают модели с историческими оценками, даже если они сняты или пропали из каталога.
- Arena пока не влияет на этот рейтинг.

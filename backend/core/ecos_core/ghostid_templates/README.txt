Подключение входа через GhostID

Сервер: __PLATFORM__.

Создай приложение в GhostStudio: название, домен сайта, аватар и язык сервера.
Архив уже содержит настройки твоего приложения. После смены домена или языка скачай новый архив.

Node.js: положи ghostid.mjs рядом с серверным кодом. Подключи обработчик из connect.mjs до остальных маршрутов и до обработчика ошибки 404. Переменная app в примере — твоё приложение Express или совместимый сервер.

PHP: положи __PHPFILE__ в корень своего сайта. Файл должен исполняться PHP, а не скачиваться как исходный текст. Чтобы получить данные в своём коде, передай функцию в ghostid_handle в конце файла.

Проверь адрес __VERIFY__. Он должен отвечать строкой подтверждения. Нажми «Подтвердить сайт» в GhostStudio: это включит приложение. Отдельный ключ или пароль приложения не требуется.

Вставь три строки из button.html на страницу сайта. Они загружают нашу кнопку и определяют приложение по домену. Если на домене несколько приложений, готовый код уже содержит идентификатор нужного.

Адрес начала входа: __START__
Адрес возврата: __CALLBACK__
Оба адреса должны обслуживаться выданным файлом на указанном HTTPS-домене.

После согласия пользователя обработчик передаст в твою функцию:
sub — постоянный идентификатор аккаунта GhostID, строка;
username — имя пользователя;
name — открытое имя профиля;
picture — ссылка на открытый аватар или null.

Связывай аккаунты по sub. Пользователь может менять имя и аватар. Дополнительные поля, пароль, настройки защиты, почта и сессия GhostID не передаются.

Без своей функции файл просто показывает полученные открытые данные в JSON. Чтобы продолжить вход на сайте, подключи обработку user в своей серверной функции: найди или создай местный аккаунт, создай сессию своего сайта и отправь пользователя на нужную страницу. Сохранение данных в твоей базе остаётся на твоей стороне.

GhostID создаёт запрос входа, хранит проверочные значения, выдаёт одноразовый код, проверяет его и возвращает подтверждённые открытые данные. Наш файл сохраняет только временную защищённую cookie для привязки ответа к браузеру. Долговременная сессия сайта и её отзыв требуют обработки на твоём сервере.

Запрос входа действует 10 минут, код после согласия — 2 минуты. Каждый ответ можно использовать один раз. Повторный запуск входа в том же браузере заменяет предыдущую попытку для этого приложения.

При ошибке или истечении времени начни вход снова. Не записывай код входа, nonce, cookie или параметры ссылки возврата в журналы. После успешной обработки лучше вернуть пользователя на чистый адрес без параметров входа.

# GhostEcos — приватная экосистема

> **GhostEcos** — приватная экосистема цифровых сервисов (мессенджер, соцсеть, банк, ИИ и игры), альтернатива корпорациям, которые собирают данные о пользователях. Один аккаунт на всё. Без номера телефона и почты. Без рекламы и слежки. С офлайн-режимом в Android APK. Открытый код (AGPL-3.0).

## Что такое GhostEcos

**GhostEcos** — это независимая privacy-first экосистема, в которой пользователь владеет своими данными, а не корпорация. Все сервисы связаны одним аккаунтом и общими принципами приватности.

**Главная идея:** дать человеку всё необходимое для общения, социализации, финансов и развлечений — без слежки, рекламы и привязки к телефону или почте.

### Принципы

- **Один аккаунт на всё** — мессенджер, соцсеть, банк, ИИ, игры.
- **Без номера телефона и почты** — регистрация только по имени пользователя и паролю.
- **Без рекламы и слежки** — никакой аналитики, трекеров, алгоритмической ленты.
- **Приватность по умолчанию** — E2E-шифрование, transient storage, офлайн-режим.
- **Открытый код** — AGPL-3.0, любой может форкнуть и self-host.

## Как устроена экосистема

GhostEcos состоит из нескольких сервисов, связанных общим аккаунтом и токеном сессии:

```
┌─────────────────────────────────────────────────────┐
│                    GhostEcos                        │
│  ┌───────────┐  ┌───────────┐  ┌───────────────┐  │
│  │ GhostChat │  │GhostSocial│  │  GhostBank    │  │
│  │мессенджер │  │ соцсеть   │  │ банк/NFT      │  │
│  └─────┬─────┘  └─────┬─────┘  └───────┬───────┘  │
│        │              │                │          │
│        └──────┬───────┴────────┬───────┘          │
│               │  общий аккаунт  │                   │
│        ┌──────┴──────┐  ┌──────┴──────┐          │
│        │   GhostGem    │  │  Игры /     │          │
│        │   ИИ        │  │  Premium    │          │
│        └─────────────┘  └─────────────┘          │
└─────────────────────────────────────────────────────┘
```

### Сервисы

- **GhostChat** — приватный мессенджер с E2E-шифрованием, звонками, группами, скрытыми чатами, файлами, мультидевайсом. Офлайн-режим в Android APK.
- **GhostSocial** — социальная сеть: лента, посты, репосты, теги, реакции, подписки, верификация. Хронологическая лента без алгоритмов.
- **GhostBank** — кошелёк, NFT-маркет, инвойсы, переводы, розыгрыши (beta).
- **GhostGem** — ИИ-ассистент (3 провайдера: OpenAI, Claude, Gemini). Чат с памятью, файлы, генерация изображений/видео. Без собственных ключей.
- **Мини-игры** — игры в браузере без аккаунта и установки.
- **Premium** — магазин премиум-функций.

### Как они связаны

- **Единый аккаунт** — один логин/пароль для всех сервисов.
- **Единая сессия** — токен авторизации работает везде.
- **Единая валюта (Gost)** — внутренняя экономика, NFT, розыгрыши.
- **Единые принципы приватности** — E2E, transient storage, нет слежки.

## Подробное описание сервисов

### GhostChat — приватный мессенджер

**Функции:**
- E2E-шифрование (P-256 + AES-GCM) по умолчанию.
- Текстовые сообщения, файлы, изображения, голосовые.
- Групповые чаты, скрытые чаты (PIN-код).
- Звонки (WebRTC).
- Мультидевайс (синхронизация между устройствами).
- Офлайн-режим в Android APK.
- Transient storage — сообщения удаляются с сервера после доставки.
- TOFU pinning публичных ключей (предупреждение при смене ключа).

**Экраны:**
- Список чатов, поиск по контактам.
- Окно чата с индикатором шифрования.
- Настройки приватности (кто может писать, видеть статус).

### GhostSocial — социальная сеть

**Функции:**
- Посты (текст, изображения, видео).
- Репосты, теги, реакции (эмодзи).
- Подписки (фолловинг/фолловеры).
- Хронологическая лента (без алгоритмов).
- Верификация аккаунтов.
- Поиск по тегам и пользователям.
- Миниски (компактные посты-карточки).

**Экраны:**
- Лента, профиль пользователя, страница тега.
- Создание поста (редактор с предпросмотром).
- Уведомления (реакции, подписки, упоминания).

### GhostBank — внутренняя экономика

**Функции:**
- Кошелёк с 3 валютами: Soul, Gost, Prem.
- NFT-маркет (минт, покупка, продажа, передача).
- Инвойсы (создание, оплата, отмена).
- Переводы между пользователями.
- Розыгрыши (giveaways) с призами.
- Реферальная система (бонусы за приглашения).

**Экраны:**
- Баланс и история транзакций.
- Маркет NFT (витрина, карточка NFT).
- Создание инвойса, сканирование кода.

### GhostGem — ИИ-ассистент

**Функции:**
- 3 провайдера (OpenAI, Claude, Gemini).
- Чат с памятью (история сохраняется).
- Загрузка файлов (документы, изображения).
- Генерация изображений и видео.
- Без собственных ключей — всё через единый интерфейс.

**Экраны:**
- Окно чата с выбором модели.
- Панель файлов и истории.
- Галерея сгенерированных изображений.

### Мини-игры

- Игры в браузере без аккаунта и установки.
- Pixel-война, и другие (roadmap).

### Premium

- Магазин премиум-функций.
- Оплата через Telegram bot + web.

## FAQ (частые вопросы)

**Q: Нужен ли номер телефона или почта для регистрации?**  
A: Нет. Только имя пользователя и пароль.

**Q: Как восстановить аккаунт, если забыл пароль?**  
A: Восстановления нет. Пароль хранится только у вас (E2E). Потеря пароля = потеря аккаунта. Это цена приватности.

**Q: Где хранятся сообщения?**  
A: Ciphertext удаляется с сервера после доставки (transient storage). Локально — в IndexedDB браузера.

**Q: Можно ли self-host?**  
A: Да, AGPL-3.0. См. гайд ниже.

**Q: Какие игры есть?**  
A: Pixel-война и другие (в разработке). Аккаунт не нужен.

**Q: Какой ИИ используется?**  
A: 3 провайдера (OpenAI, Claude, Gemini) через единый интерфейс. Ключи не нужны.

**Q: Есть ли модерация в соцсети?**  
A: Да, базовая (блокировка, жалобы). Верификация аккаунтов.

**Q: Лента хронологическая или с рекомендациями?**  
A: Хронологическая, без алгоритмов.

**Q: Что такое Soul/Gost/Prem?**  
A: Внутренние валюты экосистемы. Gost — за активность и рефералы. Soul и Prem — премиум-валюты.

**Q: Работает ли офлайн?**  
A: Да, в Android APK есть офлайн-режим.

## Гайды

### Self-host (развёртывание своего сервера)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/wakionecontact-source/ghostecos.git
   cd ghostecos/server/social
   ```
2. Создайте venv и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r social_requirements.txt
   ```
3. Запустите сервер:
   ```bash
   uvicorn social_app:app --host 0.0.0.0 --port 8005
   ```
4. Настройте nginx (пример в `server/nginx/`).
5. Включите systemd (примеры в `server/deploy/`).

### Регистрация

1. Откройте https://ghostecos.duckdns.org.
2. Нажмите «Регистрация».
3. Введите имя пользователя и пароль.
4. Подтвердите возраст 18+.
5. (Опционально) Введите код приглашения.
6. Готово — вы в экосистеме.
7. Сохраните выданную сид-фразу — она нужна для восстановления аккаунта при утере пароля.

### Использование

- **Чат:** создайте чат, отправьте сообщение. Ключи генерятся автоматически.
- **Соцсеть:** публикуйте посты, подписывайтесь, ставьте реакции.
- **Банк:** получите Gost за регистрацию, переводите друзьям, покупайте NFT.
- **ИИ:** выберите модель в GhostGem, задайте вопрос, загрузите файл.

## Технические детали

### Архитектура

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  Web (PWA)  │  │ Android APK │  │  Desktop    │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │                │                │
       └────────┬───────┴────────────────┘
                │ HTTPS + WSS
       ┌────────▼────────────────────────┐
       │ nginx (TLS, static, routing)    │
       └────────┬────────────────────────┘
                │ proxy_pass
       ┌────────▼─────────────────────────┐
       │ FastAPI / uvicorn :8005          │
       │ - social_router (/api/soc/*)     │
       │ - chat_router (/api/chat/*)      │
       │ - ws_hub (WebSocket pub/sub)     │
       └────────┬─────────────────────────┘
                │ sqlite3 + WAL
       ┌────────▼─────────────────────────┐
       │ ghostchat.db (одна БД на всё)    │
       └──────────────────────────────────┘
```

**Стек:** Python 3.12 / FastAPI / uvicorn / SQLite (WAL) / argon2-cffi / vanilla JS + Web Crypto API. Никакого React/Vue/build-step.

### Структура репо

```
server/
├── social/          # backend соцсети + банк + чат API
├── chat/            # E2E-эндпоинты и web-клиент
├── bank/            # GhostBank (кошелёк, NFT, инвойсы)
├── site/            # Лендинг
├── shop/            # Premium-магазин
├── nginx/           # Конфиг nginx
└── deploy/          # systemd unit-файлы
```

### Безопасность

- **Argon2** для паролей.
- **E2E:** приватный ключ генерится в браузере, хранится в IndexedDB как `extractable=false` CryptoKey.
- **Transient storage:** ciphertext удаляется после доставки.
- **TOFU pinning** публичных ключей (предупреждение при смене).
- **Rate-limits** на все write-эндпоинты.
- **WAL + BEGIN IMMEDIATE** для атомарности (деньги).
- **CSP-friendly:** нет inline-eval, трекеров, аналитики.
- **AGPL-v3** — хостер обязан открыть исходники.
- **Сид-фраза** — выдаётся при регистрации для восстановления аккаунта при утере пароля.

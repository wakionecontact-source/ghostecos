# GhostEcos — набор иконок (GE Icons)

Свой набор иконок для всей экосистемы GhostEcos (GhostChat + GhostSocial) вместо
шаблонных. Стиль задаёт маскот Ghostik с аватарки: тонкая скруглённая белая
обводка на фиолетовом, дружелюбные формы. У **каждой** иконки — своя анимация,
завязанная на её элементы (а не общее подпрыгивание).

## Где что лежит

- `showcase.html` — живая галерея и **источник правды**. Открой в браузере:
  на загрузке прокатывается волна анимаций, наведи на иконку — повтор.
  Все иконки описаны как данные в массиве `ICONS` внутри файла.
- (дальше) `sprite.svg` — собранный SVG-спрайт для веба.
- (дальше) `ge_icons.ttf` + `ge_icons.dart` — иконочный шрифт для Flutter-обёртки.

## Фирменные цвета

- `#3B0C93` — глубокий фиолетовый (фон лаунчера, `android/.../colors.xml`)
- `#7C3AED` — основной в вебе (`--primary`) и Flutter (`primary2`)
- `#A855F7` — светлый акцент Flutter (`primary`)

Сами иконки рисуются в `currentColor` — цвет наследуется от места вставки.

## Как устроена иконка

Каждая запись в `ICONS`:

```js
{ g:'Группа', n:'имя', cls:'i-имя', l:'Подпись',
  fa:'имя-в-fontawesome', mi:'имя-в-material',
  svg:'<path .../>' }
```

- `viewBox="0 0 24 24"`, обводка 2px, скругления, `currentColor`.
- `fa` / `mi` — на какую шаблонную иконку маппится (для замены в коде).
- Подвижные части помечаются классом (`door`, `lens`, `shackle`, `l1/l2/l3`…),
  на них вешается анимация — см. блок `.tile.play .i-… {…}` и `@keyframes`.

## Что меняем (по разведке кода)

- **Веб** (`web_split/out/ghostsocial`, `…/chat`) — сейчас Font Awesome 6.5.1,
  ~45 иконок. Меняем `<i class="fa-…">` → инлайн-SVG/спрайт.
- **Flutter** (`app/desktop_wrapper/lib/screens/*`) — сейчас Material Icons,
  ~120 иконок. Меняем `Icons.*` → свой иконочный шрифт `GeIcons.*`.

# Вертикальные видео — GhostChat (чат как главный продукт)

Позиционирование: **флагман — чат.** Всё остальное (соцсеть, кошелёк, звонки) — упоминается вскользь или не упоминается вообще.
Проверено по живому продукту: **GhostChat 1.2.1** + код `server/chat/chat_router.py`.

Формат: 1080×1920, 15–25 сек, текст на экране, без закадрового голоса.

**Три вещи, которые у GhostChat действительно есть и которых нет у других.** На них и строим — потому что их можно показать, а не рассказать:

| Что | Чем подтверждается | Ролик |
|---|---|---|
| Сервер получает только шифр | `chat_dm` принимает только base64-шифр (`_is_b64`), ключ не покидает клиент | №1 |
| Сообщение удаляется после доставки | `/ack` делает `DELETE FROM chat_dm`, статус «доставлено» выводится из **отсутствия** строки | №2 |
| Работает без интернета | локальный чат по общей сети/Bluetooth | №3 |

## 0. TikTok из России — что решает мод, а что нет

| Факт | Следствие |
|---|---|
| Загрузка новых видео с российских аккаунтов закрыта с 2022 г. | Мод это снимает |
| Российский IP не попадает в глобальные рекомендации | Мод подменяет страну в запросах — тоже снимает |
| Но: заходить всё равно надо **с IP страны, где TikTok работает полностью** | Мод **не заменяет** прокси. RU / IN / NP / AZ / AF не подходят |
| TikTok периодически банит аккаунты за неофициальные клиенты | Единая точка отказа, если весь канал — один мод-аккаунт |

Чеклист мод-маршрута:

- [ ] Прокси/VPN в подходящей стране
- [ ] Регион выставлен в настройках самого приложения
- [ ] Геолокация у приложения запрещена
- [ ] Кэш очищен после смены IP
- [ ] Мод с 4PDA, не из случайного Telegram-канала (под видом модов — трояны)
- [ ] Копии роликов лежат локально: после обновления мода пропадают подписки, лайки и свои видео

Источники: [Unisender](https://www.unisender.com/ru/blog/tiktok-v-rossii-chto-proiskhodit-s-platformoj/), [ProTraffic](https://protraffic.com/baza-znaniy/kak-vykladyvat-tiktok-v-rossii-v-2026-godu-polnyj-razbor-153628.html), [Лента.ру](https://lenta.ru/articles/2026/03/30/mody-dlya-tiktok/amp/).

**Публикуем один раз — в пяти местах.** Приоритет по отдаче бесплатно: VK Клипы → YouTube Shorts → Дзен → TikTok → Reels (Meta признана в РФ экстремистской, платная реклама там запрещена законом).

## 1. Правила формата

1. Хук — первые **1,5 секунды**. Движение + крупный текст + звук. Статичный первый кадр = пролистнули.
2. Не начинать с логотипа и названия продукта.
3. Одно видео = одна мысль.
4. Текст 3–6 слов, крупно, с плашкой (на скринах кода и терминала белый текст не читается).
5. Петля: последний кадр ≈ первый.
6. Один призыв к действию.
7. Не врать и не преувеличивать: всё, что в кадре, должно воспроизводиться на живом продукте.
8. Звук — трендовый, из библиотеки CapCut (треки из загрузок TikTok = риск теневого бана).
9. Публикация: будни 18:00–22:00 МСК, выходные 12:00–20:00.
10. Экспорт: MP4, H.264, 1080×1920, 30 или 60 fps, 10–12 Мбит/с.

## 2. Скрипты

### Скрипт 1. «Я автор этого мессенджера. Прочитать ваши сообщения я не могу» ⭐

**22 сек.** Веб, два аккаунта (один — в приватном окне), DevTools → Network → WS.
**Почему главный:** это единственный хук, который бьёт в чат, звучит как признание, а не как реклама, и проверяется на экране за 10 секунд.

**Подготовка:** между аккаунтами уже есть переписка. В DevTools выбран сокет, в ленте видны кадры. Одно контрольное сообщение отправлено заранее.

| Время | Кадр | Текст на экране |
|---|---|---|
| 0,0–1,5 | DevTools, в потоке WS летят кадры `{"ciphertext":"eyJ…"}` | **Я не могу прочитать ваши сообщения** |
| 1,5–4,5 | Alt-tab в чат: тот же диалог читаемым текстом | **А у вас они читаются** |
| 4,5–8,0 | Назад в DevTools, зум на строку с base64 | **Потому что до сервера доходит вот это** |
| 8,0–9,5 | Крупно, на 1,5 сек — просто одна длинная строка base64, без пояснений | **—** (пауза, дать разглядеть) |
| 9,5–14,0 | Показ кода: `X25519` → общий ключ → `AES-256-GCM`. Ключ создаётся на устройстве, `extractable=false` | **Ключ рождается на устройстве и его нельзя выгрузить** |
| 14,0–18,0 | Экран репозитория, лицензия AGPL-3.0 | **Я не прошу верить на слово. Код открыт** |
| 18,0–22,0 | Лого + URL, кадр ≈ первый (для петли) | **ghostecos.duckdns.org** |

**Описание:**
> Я написал этот мессенджер и специально сделал так, чтобы не мог прочитать вашу переписку. Ключ создаётся на вашем устройстве, до сервера доходят только зашифрованные байты.
> Код открыт, можно проверить.
> #приватность #шифрование #e2e #opensource #индиразработчик

### Скрипт 2. «Сообщение удаляется с сервера после доставки» ⭐

**20 сек.** Терминал (SSH на сервер, `sqlite3`) + телефон. Самый убедительный ролик из всех — потому что показывает базу, а не интерфейс.

**Подготовка:** доступ к серверу, два аккаунта, один офлайн (чтобы сообщение легло и лежало).

**ВАЖНО ПЕРЕД СЪЁМКОЙ.** Колонка называется `chat_dm.text`, но хранит **base64-шифр**, а не открытый текст. Если снять `SELECT *` — в кадре будет колонка с именем `text`, и это выглядит как плейнтекст. Найдётся человек, который сделает из этого скриншот против тебя. Поэтому в кадре показывай только `COUNT(*)` или длину:

```
sqlite> SELECT COUNT(*) FROM chat_dm WHERE receiver_id=2;
1
```

| Время | Кадр | Текст на экране |
|---|---|---|
| 0,0–2,0 | Терминал: `SELECT COUNT(*) FROM chat_dm WHERE receiver_id=2;` → **1** | **Сообщение лежит на сервере. Прямо сейчас** |
| 2,0–5,0 | Телефон отправителя: сообщение ушло, вместо галочки — значок 💾 | **Отправлено. Дискета = копия ещё на сервере** |
| 5,0–8,0 | Получатель открывает чат → на телефоне отправителя 💾 меняется на ✓✓ | **Доставлено и прочитано** |
| 8,0–12,0 | Тот же запрос в терминале второй раз → **0** | **Сервер удалил. Совсем** |
| 12,0–16,0 | Быстрый проход по 5 шагам протокола: шифр → сохранено 💾 → доставка → подтверждение → сервер удаляет | **Это не архив. Это транзит** |
| 16,0–20,0 | Лого + URL | **ghostecos.duckdns.org** |

**Почему это честно:** статус «доставлено» в коде выводится из **отсутствия** строки — сервер физически не может показать сообщение повторно после доставки.

**Описание:**
> Показал базу своего мессенджера до и после доставки. Сообщение живёт на сервере только до момента, когда получатель его забрал, — потом удаляется.
> Это не архив переписки. Это транзит.
> #приватность #базаданных #sqlite #индиразработчик #opensource

### Скрипт 3. «Авиарежим. Сообщение дошло.»

**18 сек.** Два телефона, одна Wi-Fi сеть.
**Почему работает:** физически невозможно → смотрят до конца. И это правда, и это про чат.

**Подготовка:** два аккаунта, оба в одной сети, локальный чат включён. Мобильный интернет выключен **до** съёмки — иначе «дошло через сервер» и ролик превращается в ложь.

| Время | Кадр | Текст на экране |
|---|---|---|
| 0,0–1,5 | Рука включает авиарежим на обоих телефонах, иконки сети гаснут — крупно | **Интернет выключен. Оба телефона** |
| 1,5–4,5 | Раздел локального чата: идёт поиск, устройство рядом найдено | **Приложение нашло телефон рядом** |
| 4,5–8,0 | Печатаешь → сообщение появляется на втором телефоне, статус «доставлено» | **Доставлено. Без интернета** |
| 8,0–12,0 | Пересылаешь фото и файл, приходят | **Фото и файлы — тоже** |
| 12,0–15,0 | Авиарежим выключен → в чате режим меняется на серверную доставку | **Появился интернет — вернулся к серверу. Сам** |
| 15,0–18,0 | Лого + URL, кадр ≈ первый | **ghostecos.duckdns.org** |

**Описание:**
> Отправил сообщение с телефона на телефон в авиарежиме. Работает по локальной сети или Bluetooth — интернета нет вообще.
> В метро, на даче, на фестивале, где сеть не тянет.

## 4. Как снимать

- **Экран:** OBS Studio, сцена 1080×1920, источник — окно браузера (DevTools → Toggle device toolbar → 1080×1920). Курсор видимый, потом ускорить в 1,5–2×.
- **Телефон:** `scrcpy` по USB — чистая картинка экрана без дрожания.
- **Два телефона живьём** — второй телефон, вертикально, с рук.
- **Монтаж:** CapCut. Ни одного кадра дольше 3 секунд. Резы — по битам.
- **Терминал:** увеличить шрифт до 18–20 pt, тёмная тема, окно ровно по центру, лишние вкладки закрыть. Команду печатать заранее в буфер, а не набирать в кадре.
- **Плашка под текст обязательна** — на скринах кода и терминала белый текст пропадает.
- **Секретные данные:** перед съёмкой терминала убрать из кадра IP, пути, ключи, ник хоста. Записать `screen`-сессию лучше в отдельном окне с чистым prompt.

## 6. Метрики

- **Регистрации по дням** — `/admin/stats`, методом «спайк в день публикации».
- **UTM в реф-ссылке:** `?ref=waki_one&utm=vk_clips`, `utm=shorts`, `utm=tiktok`.
- **В самих видео:** досмотры и первые 2 секунды. Низкие досмотры → виноват хук. Высокие досмотры, но нет регистраций → виноват оффер и ссылка, не продукт.
- **Порог:** стабильно >5 регистраций в день — канал найден, удваивать.

## 7. Чего не делать

- Не покупать накрутку и не бустить прокси-аккаунтами.
- Не делать многоуровневую рефералку.
- Не рассылать в личку — бан.
- Не подавать соцсеть и кошелёк как главное: лицо — чат.
- Не показывать в кадре фичи, которых нет в 1.2.1.
- **Не снимать `SELECT *` из `chat_dm`:** колонка называется `text`, хотя хранит шифр.
- Не публиковать чужие переписки в демо E2E — только свои тестовые аккаунты.
- Не называть конкурентов в тексте и не приписывать им то, чего не видно в кадре.

GhostEcos — база знаний проекта (для обучения нейросети)

=== ЧТО ТАКОЕ GHOSTECOS ===

GhostEcos — открытая privacy-first экосистема: мессенджер с end-to-end шифрованием, соцсеть без централизованного алгоритма (алгоритм ленты полностью на устройстве пользователя, сервер не знает предпочтений), внутренняя игровая экономика с тремя валютами, NFT-маркет, и мини-игра "своя страна на карте". Один аккаунт на всю экосистему (SSO).

Главная идея для маркетинга: "Приватный мессенджер, в который встроена целая экосистема — соцсеть, кошелёк, NFT, и даже своя страна на карте". GhostChat — основной продукт. Всё остальное подаётся как "внутри одного приложения", не как отдельные продукты. GhostNation (игра про страны) намеренно не выпячивается как главный продукт — она бонус, не лицо экосистемы.

Позиционирование на рынке: "одно приложение вместо пяти" — с приоритетом на приватность (нулевые метаданные, шифрование на устройстве, независимая инфраструктура).

Автор — Waki (Telegram: @waki_one). Демо: https://ghostecos.duckdns.org. Статус: ранняя бета. Лицензия: AGPL-v3 (форки, публично хостящие сервис, обязаны открывать исходники изменений). GitHub: github.com/wakionecontact-source/ghostecos.

Changelog: единственный формальный релиз [0.1.0] от 2026-05-30 — первый публичный релиз, AGPL-3.0. Включает: E2E P-256/AES-GCM, transient storage, TOFU pinning серверного identity-ключа, миниски (48ч), 3 валюты, NFT-маркет с 10% комиссией на P2P-сделках, кастомные юзернеймы за Soul.

=== СЕРВЕРНАЯ ИНФРАСТРУКТУРА ===

Прод-сервер: IP 155.212.166.221 (хостнейм ilushashishkov1.fvds.ru, он же ghostecos.duckdns.org), Ubuntu 24.04.4, 1 ядро, ~1.8GB RAM. Все сервисы работают через nginx (HTTPS :443 + :80).

Один общий SQLite-файл `/opt/ghostchat/ghostchat.db` (~106МБ) обслуживает и мессенджер, и соцсеть — аккаунты (users, user_devices) общие на всю экосистему.

Сервисы (systemd):
- ghostchat.service — порт 8000, `main_remote:app`, мессенджер "Relay Server v2.0"
- ghostsocial.service — порт 8005, `social_app:app`, соцсеть + отдельный веб-чат
- ghostnation.service — порт 8010, `server:app`, GhostNation ("мир"/страны на карте)
- shop_web.service — порт 8001, веб-часть магазина Premium (`web_only.py`)
- nginx.service — реверс-прокси

--- Мессенджер: main_remote.py (порт 8000), "Relay Server v2.0" ---

Полностью переписан с версии v1.9: единая БД, aiosqlite (асинхронный SQLite), JWT (HS256, PyJWT) с revoke-таблицей, Argon2 для хэширования паролей, DDoS-защита с bypass-токеном (заголовок X-Ghost-Bypass), метаданные только в RAM.

WebSocket /ws — эфемерная X25519-сессия на каждое соединение, сервер сразу шлёт {"type":"hello","pub":...}. Fallback через query-параметры для обратной совместимости.

Роутеры: auth (регистрация/логин/устройства/Device Trust Flow с 6-значным кодом), users (профиль/контакты), channels (каналы: CRUD, участники, сообщения, ключи, заявки на вступление, реакции), files (загрузка/скачивание, шифрование на файл, TTL), shop (тикеты поддержки/магазина, выдача премиума через internal-эндпоинты), support (чат поддержки), admin (управление пользователями/устройствами/каналами, статистика).

Device Trust Flow (вход с нового устройства): approve → code_ready → login_submit_code → code_verify, взаимный 6-значный код между новым и доверенным устройством.

Индикаторы доставки сообщений: серый круг → красная дискета (сохранено на сервере >10с) → одна галка (доставлено) → две галки (прочитано) → крестик (не доставлено за 1 час).

Фоновые задачи: heartbeat каждые 10с (проверка живости соединений, peer_online/offline), очистка просроченных файлов, раз в сутки — глубокая очистка БД.

--- GhostSocial + встроенный веб-чат: social_app.py (порт 8005) ---

Отдельное FastAPI-приложение, Swagger полностью отключён. Глобальный rate-limit: 600 запросов/60 сек на ключ (по IP или токену) — введён после пентеста самим Waki (2026-06-20): "одна DevTools-консоль с for-loop клала сервер за секунды, 61 из 176 эндпоинтов ходили без лимита".

Подключает три роутера: social_router.py (~417КБ, ~90 эндпоинтов, префикс /api/soc), chat_router.py (веб-чат v1, /api/chat, ~52 эндпоинта), chat_router_v2.py (веб-чат v2, Signal-style, опционально).

Группы эндпоинтов social_router.py: аккаунт (register/login/guest/recovery), посты (upload/feed/newhere/search/CRUD), профиль (follow, avatar), реакции/комментарии, уведомления, link preview + OG-картинки (динамические превьюшки для шаринга — user/post/wrapped/group/channel/giveaway/miniska/nft), Wrapped (годовой отчёт а-ля Spotify Wrapped), репосты, жалобы/модерация, статусы (stories), модерация (overwatch-очередь, заявки в модераторы, голосования, промоушен/демоушен), miniska (короткие видео, аналог Reels), реферальная система, SSO, экономика (Gost — кошелёк/транзакции/daily reward), Soul (перевод/транзакции), NFT (каталог/листинги/минт/покупка/трансфер), инвойсы (premium-платежи), кастомные юзернеймы (маркетплейс имён), гивевеи, сохранённое (saved posts).

Около 40 таблиц с префиксами soc_*/chat_* в общей БД (посты, комментарии, реакции, подписки, репосты, сохранённое, уведомления, опросы, жалобы, модерация, гивевеи, кошельки/транзакции Gost и Soul, NFT-каталог/листинги, инвойсы, юзернеймы + отдельно chat_dm/chat_dm_sealed/chat_dm_v2/chat_groups для веб-чата).

Дизайн экономики валют (комментарий в коде): gost — бесплатная, за активность, non-transferable, тратится только на первичные NFT; soul — transferable, cap-эмиссия, эмитируется через выкуп NFT; prem — украшения, не пересекается с другими валютами.

--- GhostNation (порт 8010) — "мир"/своя страна на карте ---

Небольшое отдельное FastAPI-приложение, переиспользует аккаунты GhostEcos (тот же JWT-секрет). Пользователь застолбляет границу страны на реальной спутниковой карте (Leaflet + Esri World Imagery), строит внутри неё (дома, магазины, деревья, дороги) за валюту Gost. Экономика: старт-бонус 1500 gost, застолбление 300 gost/км², дом 40 gost, магазин 70 gost, дерево 4 gost, дорога 0.6 gost/метр. Своя БД nation.db.

Изначально задумывалась как полностью клиентская (localStorage, без бэкенда), но серверная версия (`server.py`) уже добавлена и переиспользует аккаунты. Планы на будущее (README GhostNation): экономика с налогами с площади, больше типов построек (фермы, заводы, столица), дороги по кривой, скриншот-открытка страны для шаринга, посадка/высадка из машин с построением маршрута.

=== МОБИЛЬНОЕ ПРИЛОЖЕНИЕ — ТЕКУЩЕЕ (приоритет разработки) ===

Путь в репозитории: _ghost_app/app/ghostchat. Пакет называется "ghost", версия 1.1.13+18 (в UI кое-где остался устаревший хардкод "v1.1.10" — косметика, не влияет на логику). Описание: "приватный мессенджер с экосистемой (чат, лента, банк) на Mesh + жидкое стекло". Нативное приложение без WebView, кроссплатформенное: Android, iOS, Windows, Linux, macOS из одного кода.

Это НЕ урезанная версия старого приложения, а полный rewrite — сменил курс с mesh-сети на веб-совместимую экосистему. Выиграл: соцсеть/экономику/FCM/typing/реакции/TLS. Потерял: весь security/mesh/каналы/мульти-аккаунт слой старой версии (частично уже возвращается).

Приложение общается с бэкендом: https://ghostecos.duckdns.org, /api/chat (мессенджер), /api/soc (соцсеть/банк), WS wss://ghostecos.duckdns.org/api/soc/ws.

--- Навигация: только 2 вкладки (важный факт) ---

Несмотря на то, что pubspec.yaml и старые комментарии в коде говорят "4 таба: Чат/Лента/Банк/Профиль", РЕАЛЬНО в коде подключены только Чаты и Профиль. Экраны Ленты (feed_screen.dart, social_pane.dart), Банка (wallet_screen.dart), NFT (nft_screen.dart) и Wrapped (wrapped_screen.dart) полностью написаны, со своей рабочей бизнес-логикой и обращениями к серверу, но физически НЕ подключены ни к какой навигации — это "осиротевшие" модули, ожидающие возврата вкладок в будущих milestone'ах (внутренние метки M5-M7 в комментариях кода).

Профиль (свой) — минималистичный: аватар-инициал, пункт "Настройки", "Мои устройства", кнопка выхода. Профиль ДРУГОГО пользователя — полноценный (открывается по тапу на собеседника в чате): аватар, статус, репутация, счётчики постов/подписчиков, follow/unfollow, лента его постов — это единственная точка, где соц-функционал реально виден пользователю, хотя своей вкладки "Лента" нет.

--- Что реально работает ---

- LAN/BLE/Wi-Fi Direct локальный чат ("устройства поблизости") — полноценно, транспорты стартуют на уровне всего приложения (не только на экране сканирования), сообщения принимаются в фоне, есть приоритет транспортов, keepalive, определение сигнала.
- Гостевой режим — работает полностью без сервера (только LAN-чат), локальный UUID-токен, сервер вообще не используется.
- E2E-шифрование — ДВЕ параллельные живые схемы одновременно: "v1" (ECDH P-256 + HKDF-SHA256 + AES-256-GCM, байт-в-байт совместима с WebCrypto веб-фронта) для DM через сервер, и "v2" Signal-style (Ed25519 identity из BIP-39 seed-фразы + X25519 per-device + эфемерные ключи на сообщение) для LAN-сообщений и нового серверного протокола.
- Авторизация — логин/регистрация/гость, чекбоксы 18+ и согласия с условиями, токен в secure storage.
- Настройки — тема, разрешения, ключи шифрования (просмотр seed-фразы, облачный бэкап, перегенерация), устройства, избранное, о приложении.
- Реакции — в чате работают.
- Диктофон/голосовые сообщения — запись через package:record прямо в чате (не отдельная скрытая кнопка как в старом приложении), волна амплитуды, воспроизведение.
- Медиа-вложения — фото/видео (со сжатием и превью)/файлы/камера, встроенный просмотрщик (видео не уходит во внешнее приложение).
- Устройства/сессии — список устройств аккаунта, отзыв (revoke), детект VPN.
- Push-уведомления — локальные + FCM (push не содержит текста сообщения, только сигнал подтянуть непрочитанное — приватность).
- Foreground-сервис (Android) — держит процесс живым.
- Смена темы — набор пресетов-палитр.

--- Что написано, но ОТКЛЮЧЕНО от навигации (готовый код без входной точки) ---

- Соцсеть/лента: посты, реакции, репосты, комментарии с реплаями, опросы/квизы, поиск, уведомления — весь протокол реализован в feed_repo.dart/social_repo.dart.
- Миниски (короткие видео, аналог Reels) — экран создания есть, в ленту не встроен.
- Банк/экономика: кошелёк (Gost/Soul/Prem, история транзакций, daily reward), NFT-витрина (каталог/маркет/моя коллекция), Wrapped (годовой отчёт).
- В чате есть кнопка "кошелёк" — прямо в коде помечена комментарием "заглушка до GhostBank" (отправка денег в переписке).
- Геолокация во вложениях чата — тоже заглушка.

--- Чего нет вообще (не найдено в коде) ---

- Каналы/группы (в смысле мессенджера) — только зарезервированный префикс "g:" в модели данных, ни одного экрана создания/управления группой.
- Паник-пароль / dead man switch — не найдено вообще (единственное упоминание "panic" — мёртвый метод wipeAll() в неиспользуемом WIP-скелете).
- Мультиаккаунт — не найдено, смена аккаунта = полный logout + повторный вход.

--- Архитектура: живое vs мёртвое (важно не путать) ---

Живая система: lib/main.dart (точка входа) → lib/screens/* + lib/services/* (16 файлов: api_client, auth_service, chat_repo, crypto_service, crypto_v2, db_service, fcm_service, feed_repo, foreground_service, lan_chat_store, notification_service, permissions_service, search_service, social_repo, theme_service, ws_client) + lib/core/local/* (LAN/BLE/WiFi Direct транспорты).

Мёртвая система: lib/app.dart, lib/features/*, lib/core/api/*, lib/core/crypto/*, lib/core/storage/*, lib/core/models/*, lib/shared/* — отдельное, изолированное дерево, ни разу не изменялось с одного снапшот-коммита (Jun 25), пока живая часть получила уже 2 новых релиза. Это заброшенный WIP-скелет попытки переписать приложение в духе features/-модулей. lib/app.dart нигде не подключается — main.dart импортирует только живую часть.

Внутренние roadmap-метки в комментариях кода: M4...M9 — например "Заглушки пока (M5-M7 их наполнят)", "профиль минимальный — будет наполняться в M5+", sqlite desktop FFI отключён с комментарием "вернём в M9", кастомный акцент темы отложен на M8.

=== МОБИЛЬНОЕ ПРИЛОЖЕНИЕ — СТАРОЕ (ghostchat_mobile, v1.19.3, заброшено) ===

Путь: ghostchat_mobile/ (в корне репозитория). ApplicationId: online.ghost_chat.ghostchat_mobile. Это был релизный мессенджер до перехода на новую версию, сейчас заморожен ("заброшена"), код остаётся для истории/сравнения.

Ключевое отличие философии: standalone E2EE-мессенджер с mesh-акцентом (LAN/BLE/WiFi Direct как равноправные каналы), крипто x25519/Ed25519 (НЕ P-256), бэкенд только main_remote (:8000), не знает о GhostSocial вообще.

Фичи, которых НЕТ в новом приложении, но БЫЛИ в старом:
- Мультиаккаунт до 4 профилей с полным переключением всех синглтонов.
- Паник-пароль: несколько паник-кодов, каждый со своим списком скрываемых чатов, опциональный автозапуск скрытой записи диктофона при вводе.
- Отдельный полноценный диктофон (core/dictaphone.dart): скрытый рекордер с таймером, стоп-кодом (соль+SHA-256), лимитами по времени/размеру, форматы AAC/WAV, список записей с плеером — не путать с обычными голосовыми сообщениями в чате нового приложения.
- VPN-детект и IP-мониторинг: определение VPN по именам сетевых интерфейсов (tun/ppp/tap/utun/ipsec/wg), фиксация "обычного" IP и предупреждение при расхождении.
- Смена иконки приложения — 10 цветовых вариантов через android activity-alias, плюс кастомная иконка из файла.
- Каналы/группы с E2E (общий групповой ключ, оборачиваемый персонально каждому участнику), заявки на вступление, публичные/приватные.
- 26 разрешений устройства в 7 категориях (messaging/files/contacts/chats/devices/profile/security), уровни доверия.
- Блокировка скриншотов с релеем состояния собеседнику.

Архитектурная особенность (баг): сосуществуют ДВЕ несвязанные LAN-подсистемы — старый глобальный синглтон lanService (ключует по username) и новый агрегатор localHub (ключует по deviceId, но в нём зарегистрированы только Bluetooth и WiFi Direct — сам LanTransport не зарегистрирован нигде из-за конфликта порта со старым lanService). То есть заявленный "тройной mesh" реально состоит из старого отдельного LAN + нового BT/WD, а не единой системы.

=== ВЕБ-ФРОНТЕНД GHOSTSOCIAL ===

Путь: server/social/frontend/ (socialprotot.html + static/app.js ~6000 строк + static/style.css). Vanilla JS SPA без сборки, PWA (можно установить на телефон/десктоп). Тёмная тема, акцент #7c3aed/#a855f7, шрифт Inter.

Функционал: авторизация (вход/регистрация/гость, SSO через cookie+Bearer), лента с сортировками (для вас/новые/топ/подписки/рандом/старые), pull-to-refresh, бесконечная подгрузка, real-time через WebSocket. Создание поста (текст до 1000 символов, фото/видео/аудио, опросы и квизы, NSFW-флаг, миниски с обязательными хэштегами). Реакции эмодзи, двойной тап для лайка, репосты, сохранение, "поделиться" (в GhostChat/наружу/для Discord), скачать пост как картинку, жалобы, скрытие/блокировка автора. Комментарии с вложенными ответами. Миниски — вертикальный автовоспроизводящийся фид коротких видео с автоудалением через 48 часов. Профиль (свой и чужой) с Wrapped, редактированием, удалением аккаунта (с предупреждением про переход баланса/NFT системе).

Алгоритм ленты — полностью клиентский (localStorage), сервер не видит предпочтений пользователя — явно подчёркнуто в UI как приватность.

Кошелёк (виджет внутри соцсети): Gost (активна, бесплатная за активность), Soul и Prem (помечены "скоро", заблокированы в UI). Таблица начисления Gost: дневной бонус +10, свой пост +5, лайк +1, коммент +2, новый подписчик +5. Минт поста как NFT (мастер из 4 шагов: тираж, цена). Полноценный NFT-маркет — в отдельном модуле /bank/ (GhostBank).

Модерация: заявки в модераторы, overwatch-очередь жалоб с голосованием, платная приоритизация проверки поста, управление модераторами (промоушен/демоушен).

=== ИЗВЕСТНЫЕ ПРОБЛЕМЫ / БАГИ (могут быть уже частично исправлены — сверяться с текущим кодом) ===

Текущее приложение (_ghost_app):
- Главный активный баг (на момент последней проверки): синк ключей при логине на свежей установке — пароль не доходит до syncKeys, генерируется новый ключ, старые сообщения не расшифровываются.

Старое приложение (ghostchat_mobile) и сервер (список более старый, апрель 2026):
- Серверные текстовые сообщения: висят с одной галочкой у отправителя, ошибки расшифровки.
- Новый чат: сообщения не доставляются, пока получатель не зайдёт в приложение.
- Файлы: тип не определяется, кнопка скачать отсутствует в меню.
- LAN: ошибка расшифровки (ключ 0 байт из-за приоритета Bluetooth).
- Bluetooth: находит сам себя.
- Паник-пароль: скрытые чаты на секунду мелькают при вводе (было в старом приложении).
- Гостевой режим: x25519 ключи не генерировались.

=== ПЛАНЫ РАЗВИТИЯ (сводка приоритетов из внутреннего анализа) ===

Рекомендованный порядок доработки текущего приложения:
1. Решить судьбу мёртвой архитектуры (core/features/app.dart) — удалить или доделать.
2. Вернуть навигацию на уже готовые вкладки Лента/Банк/Профиль (оценено как "тривиально" по сложности, "огромный эффект").
3. Починить 2FA-флоу авторизации.
4. Дальше по приоритету: каналы → паник-пароль/passcode → диктофон (отдельный, скрытый) → мультиаккаунт → mesh (LAN/BLE/WiFi Direct полноценно, оценено как "БОЛЬШОЕ" по сложности).
5. Вернуть desktop-БД (sqlite FFI) либо явно отключить desktop-сборку.

По опросу в Telegram-канале Waki (2026-07-08): пользователи хотят приложение GhostChat больше, чем сайт — мобильное приложение сейчас приоритетнее веб-версии GhostSocial при прочих равных.

Дизайн: выбрано направление UI-редизайна variant 1 (приглушённая фиолетовая палитра) по опросу в канале, ориентир на референсы shadcn/ui (ui.unlumen.com, magicui.design, smoothui.dev) — тёмная тема по умолчанию, много "воздуха", один акцентный цвет по чуть-чуть, скруглённые карточки, лёгкие микро-анимации на hover/press (AnimatedScale/AnimatedOpacity, не тяжёлые библиотеки — телефоны слабые).

=== ПРОЧИЕ ПРОЕКТЫ В РЕПОЗИТОРИИ (для полноты, не основной продукт) ===

- GHBOT/ — заброшенный ранний прототип рекламного Telegram-бота с собственной экономикой GOST, не связан с текущим стеком.
- ghostbot/ — личный служебный инструмент разработчика (Telegram-бот, запускающий Claude Code CLI удалённо), не часть продукта GhostChat.
- shop_bot/ — активно поддерживаемый магазин предзаказов Premium (Telegram-бот + сайт).
- GhostApp/ — пустая папка, не несёт содержимого.
- admin.html + admin_server.py — веб-консоль администратора сервера: файловый браузер, статистика, консоль команд (kick/broadcast/wipe_all/grant_premium и т.д.), список пользователей, живые логи через SSE, просмотрщик SQLite-таблиц.
- Бот знакомств "OKey" (bots/roulette) — на ранней стадии, есть только анкета (имя/возраст/пол/био/фото), рулетка случайных собеседников ещё не реализована.

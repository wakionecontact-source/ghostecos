# Gemini Telegram-бот

Бот на aiogram 3 + Google Gen AI SDK (`google-genai`), с очередью под лимиты
бесплатного тарифа Gemini, памятью диалога и кнопками.

## ⚠️ Важно про ключи

В исходном файле, который ты прислал, токен Telegram-бота и ключ Gemini API
были прямо в коде. **Оба стоит перевыпустить**, раз уж они оказались в чате:

- Telegram: `@BotFather` → `/mybots` → выбрать бота → `API Token` → `Revoke`.
- Gemini: в [Google AI Studio](https://aistudio.google.com/apikey) удалить
  старый ключ и создать новый.

Новые значения кладутся в `.env` (см. ниже), а не в код — так они не улетят
никуда случайно (в тот же GitHub, например).

## Установка

```bash
cd gemini_bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впиши TELEGRAM_TOKEN и GEMINI_API_KEY в .env
python bot.py
```

## Что внутри

- **Очередь под RPM/RPD** бесплатного тарифа Gemini — свои запросы бот
  считает сам (rolling-окно по минутам и по суткам) и выстраивает лишние
  в очередь, вместо того чтобы ловить ошибки от API.
- **Один активный запрос на пользователя** — если человек написал второй
  промт, пока первый ещё обрабатывается или стоит в очереди, бот вежливо
  просит подождать (текст рандомизирован).
- **Память диалога** — используется `client.aio.chats.create(...)`, так что
  Gemini помнит контекст переписки с конкретным пользователем; сбрасывается
  кнопкой «Новый диалог» / командой `/reset`, а также автоматически каждые
  `MAX_HISTORY_TURNS` обменов репликами (чтобы не разгонять расход токенов).
- **Кнопки**: «Новый диалог», «Статус», «Повторить» под каждым ответом,
  «Отменить запрос» — под сообщением о позиции в очереди.
- **Фишки Bot API**: реакции бота на сообщения (👀 когда принял запрос, 👍
  когда ответил) и кнопка «Скопировать текст» (`copy_text`) — она
  появляется только если ответ короче 256 символов (таково ограничение
  самого Telegram на этот тип кнопки).
- **Markdown → HTML**: ответы Gemini обычно приходят в Markdown, бот сам
  конвертирует их в HTML-разметку Telegram (жирный, курсив, код, ссылки,
  цитаты, списки), плюс режет длинные ответы на несколько сообщений.
- Асинхронный клиент Gemini (`client.aio...`), чтобы долгий запрос к API не
  подвешивал обработку остальных апдейтов бота.

## Настройка лимитов

Бесплатный тариф Gemini по разным моделям и аккаунтам отличается и вообще
меняется без предупреждения — актуальные цифры смотри в Google AI Studio
или на https://ai.google.dev/gemini-api/docs/rate-limits. Значения по
умолчанию в `.env.example` — консервативная отправная точка, подстрой под
себя через `RPM_LIMIT` / `RPD_LIMIT`.

Если захочешь более щедрый лимит запросов в минуту ценой чуть более простых
ответов — попробуй модель `*-flash-lite` вместо `*-flash` в `GEMINI_MODEL`
(точное имя смотри в том же списке моделей).

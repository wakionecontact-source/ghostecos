# Python с нуля — твоя карта

Ты идёшь из Scratch, и это огромный плюс: всё ядро программирования ты уже **понимаешь** — просто собирал его из блоков. Здесь те же самые идеи, только текстом. Берём **Python**, потому что он читается почти как английский и сразу показывает результат.

## Главное правило
Код нужно **писать руками**, а не копировать. Делай по чуть-чуть — 20–30 минут в день лучше, чем 4 часа раз в неделю. И перед каждым запуском попробуй **угадать**, что выведет программа.

## Ты уже это знаешь (Scratch → Python)

| В Scratch | В Python |
|---|---|
| `сказать [Привет!]` | `print("Привет!")` |
| задать `x` = 5 | `x = 5` |
| `если <…> иначе` | `if …: / else:` |
| `повторить 10` | `for i in range(10):` |
| список | `[ ]` (list) |
| Мои блоки | `def имя():` |

Видишь? По сути ничего нового. Просто новая одежда.

## Этапы

**0. Запуск.** Запустить первую программу и увидеть результат.
`print("Привет, мир!")`
*(в Scratch это зелёный флажок)*

**1. Переменные и типы.** Коробки для данных: числа, текст, да/нет.
`age = 20` · `name = "Waki"` · `is_cool = True`

**2. Ввод и операции.** Спросить у пользователя, посчитать.
`name = input("Как тебя зовут? ")`

**3. Условия.** Программа принимает решения.
`if age >= 18:` → `print("взрослый")`

**4. Циклы.** Повторять без копипасты.
`for i in range(5):` → `print(i)`

**5. Списки.** Хранить много значений в одном месте.
`friends = ["Аня", "Петя"]` → `friends[0]` это "Аня"

**6. Функции.** Свои команды — это твои «Мои блоки»! Самый важный этап.
`def hello(name):` → `return "Привет, " + name`

**7. Словари.** Список, где ищешь по имени, а не по номеру.
`user = {"name": "Waki", "age": 20}`

**8. Ошибки и отладка.** ← Вот здесь уходит беспомощность. Учишься **читать сообщение об ошибке** и чинить сам. Это навык №1, который отличает «вайбкодера» от того, кто реально понимает.

**9. Мини-проект.** Собираешь всё вместе: например, игра «угадай число» или список дел в консоли. Момент, когда ты сделал работающую штуку — и понимаешь в ней каждую строчку.

# GhostNation 🛰️ (рабочее название)

Мини-игра экосистемы GhostEcos: основай **своё государство** на реальной
спутниковой карте. Рисуешь свободные границы, ставишь дома / дороги / деревья,
игра считает площадь.

Два режима:

- **Песочница** — всё локально в браузере (`localStorage`), без аккаунта.
- **Общий мир** — вход через GhostSocial SSO (`/api/soc/sso/jwt`), страна
  застолбляется на сервере в gost-экономике, границы других игроков видны на
  карте. Переключение режима — в интерфейсе игры.

## Структура

```

├── server.py            # FastAPI: общий мир (порт 8010)
├── static/              # АКТУАЛЬНЫЙ фронт (это же лежит на сервере)
│   ├── app.js

│   ├── icons/           # SVG-иконки инструментов
│   └── vendor/leaflet-1.9.4/   # Leaflet, self-hosted (без CDN)
```

Старая папка `frontend/static/` выведена из работы 14.11.2026 — её копия лежит
в `.codex-backups/nation_legacy_frontend_20261114/`.

## Запуск (localhost)

Нужен любой статический http-сервер (через `file://` не заработает — иконки
тянутся через `fetch`). Проще всего Python:

```powershell
cd C:\Users\Home\GE\server\nation\static
python -m http.server 5500
```

Открыть → http://localhost:5500

> В `index.html` пути к Leaflet абсолютные (`/nation/vendor/leaflet-1.9.4/…`),
> поэтому при локальном запуске с корня Leaflet не загрузится. Варианты:
> поднять локально nginx с `location /nation/`, либо временно поправить пути,
> либо тестировать на сервере (см. «Деплой»).

> Карта тянет спутник с **Esri World Imagery** (без API-ключа). Если в твоём
> регионе он тупит — переключи слой на **Google** (кнопка снизу справа).

## Деплой

- Код фронта: `/var/www/nation/` (`app.js`, `index.html`, `style.css`, `icons/`, `vendor/`) — раздаётся nginx по `/nation/`.
- Бэкенд: `/opt/ghostnation/server.py`, systemd-юнит `ghostnation.service` (uvicorn, `127.0.0.1:8010`).
- БД: `/opt/ghostnation/nation.db` → симлинк на `/var/lib/ghostnation-app/nation.db`.
- nginx: `location /api/nation/` → `127.0.0.1:8010` (REST и WS в одном процессе), плюс `location = /api/nation/ws` с заголовками `Upgrade`/`Connection` и `proxy_read_timeout 3600s`.
- Ноутбучный трим памяти: `gs-mem-nation.service` (ночной рестарт).

Правки в `server/nation/` → выгрузка в `/var/www/nation/` и `/opt/ghostnation/`
(с бэкапом `*.bak.<дата>`) → `systemctl restart ghostnation` → smoke-тест
`/api/nation/health`.

### API (server.py)

| Метод | Путь | Назначение |
|-------|------|-----------|
| GET  | `/api/nation/world?minlat&minlng&maxlat&maxlng` | публично: страны в bbox (архивные не отдаются) |
| WS   | `/api/nation/ws?token=<JWT>` | мир в реальном времени: `sub` → `snapshot`, затем push `country` / `remove`. Токен не обязателен: без него просмотр разрешён, лимит 8 соединений на IP (IP берётся из `X-Real-IP` прокси) |
| GET  | `/api/nation/mine` | (auth) моя страна + начисленные налоги (офлайн не больше 72 ч) |
| POST | `/api/nation/claim` | (auth) застолбить/перечертить границу |
| PUT  | `/api/nation/mine` | (auth) сохранить состояние; можно частично — `{state: {...}, keys: ["lights"]}` |
| GET  | `/api/nation/health` | проверка живости |
| POST | `/api/nation/archive/{username}` | (внутр. токен) архивация при удалении аккаунта |
| POST | `/api/nation/cleanup_archived?days=180` | (внутр. токен) чистка архива по cron |

Экономика (`server.py`, константы сверху): старт-бонус **1500 gost**, застройка
— дом 40, магазин 70, дерево 4, станция 250, парковка 120, светофор 30, переход 10,
любая линия (дорога/переулок/жд/тропинка) 0.6/м. Население = дома×4, рабочие места
= магазины×12. Доход в час: занятый житель 2 gost, безработный 0.5. Содержание в час:
1 gost за км любой линии, станция 3, парковка 1, светофор 0.3, переход 0.1. Баланс
не уходит ниже −300, офлайн начисляется максимум 72 часа. Граница: первичный claim
оплачивается целиком, последующая **перерисовка — по приросту площади**
(300 gost/км²), сжатие и правка в прежних пределах бесплатны. Лимиты валидации:
512 точек границы, 5000 построек, 2000 линий дорог/жд/тропинок, 8192 ключа
метаданных, 8 МБ состояния. Rate limit 240 запросов/мин.

### Мир в реальном времени

Клиент в режиме мультиплеера держит WS-подписку на видимый bbox: при движении
карты переподписывается, при обрыве переподключается с backoff. В снимке и в
push приходят **границы, постройки и линии** чужих стран (до 1500 построек и
400 линий каждого типа на страну, фильтр по bbox), поэтому город соседа видно
без перезагрузки страницы. Клик по чужой границе открывает карточку страны
(владелец, площадь, дома/магазины, оценка населения). REST `/world` остаётся
фолбэком на случай недоступности WS — в нём только границы, без построек.

Лимиты WS: 8 анонимных соединений на IP (IP — из `X-Real-IP` прокси), 4 на
авторизованного игрока, 2000 всего; отправка одному клиенту ограничена 5 с,
рассылка идёт параллельно, поэтому зависший клиент не тормозит остальных.

Сохранение состояния частичное: клиент присылает только изменившиеся коллекции
(`keys`), сервер мержит их с сохранённой страной. Если сервер не принял
изменения, в верхней панели горит «Не сохранено» / «Не хватает gost».


## Управление

Панель инструментов слева:

| Инструмент | Что делает |
|-----------|-----------|
| **Границы**   | кликай по карте — ставишь точки контура страны, «Готово» замыкает |
| **Дом**       | жилой дом — **вальмовая зелёная крыша** (скаты + конёк, вид сверху), оранжевое **крыльцо** (вход) |
| **Магазин**   | коммерция — **плоская синяя кровля** с парапетом и блоком на крыше, крыльцо |
| **Дорога**    | серый асфальт с жёлтой разметкой; после рисования выбираешь **сторону тротуара** (нет / слева / справа / с обеих); точка рядом **примагничивается** |
| **Переулок**  | узкая дорога без разметки и тротуаров; снапится к дорогам/переулкам |
| **Жд**        | насыпь + шпалы + два рельса; тоже с примагничиванием |
| **Тропинка**  | пешая дорожка 1 м, сплошная серая — ложится **бордюром вдоль дороги** (под асфальтом) и соединяется с другими тропинками |
| **Дерево**    | клик сажает дерево (зелёная крона) |
| **Район**     | зона внутри границ страны (рисуешь полигоном; только внутри границ) |
| **Светофор**  | ставится только на **перекрёстке** (снап к пересечению дорог); снос инструментом сноса |
| **Переход**   | пешеходный переход (зебра) **где угодно** — клик по дороге кладёт его поперёк в этой точке (снап к дороге ≤25 м), вдали от дорог ставится свободно; снос инструментом сноса |
| **Изменить**  | клик по постройке → ручки на карте: **двигать / крутить / менять размер**, панель сворачивается |
| **Снести**    | клик по объекту удаляет его; у **дороги/тропинки удаляется только сегмент** под курсором |
| **Отмена**    | откат последнего действия (**Ctrl+Z** или кнопка-стрелка) |
| **Сохранить** | скачать государство в `.json` (**Ctrl+S**) |
| **Загрузить** | восстановить страну из `.json` |
| **Прицел**    | центрирует карту на твоей стране |

Постройки — это **footprint'ы на земле** в метрах, масштабируются вместе с картой. При
установке дом/магазин **поворачивается к ближайшей дороге входом (крыльцом) к ней** и
получает случайный размер (до 30 м на сторону); если задевает соседей — ужимается, а если
точка попала в существующее здание — переносится в свободное место. Через **Изменить** любую постройку
можно подвинуть, повернуть и отресайзить (дом/магазин 1–100 м, дерево радиус 1–50 м), а
также **скопировать/вставить** (Ctrl+C / Ctrl+V). При наведении объект подсвечивается
(в режиме сноса — красным). Дороги и жд единой ширины (7 м); где **дорога пересекает жд —
авто-переезд**, повёрнутый вдоль дороги; на пересечении дорог — **пешеходные переходы** (зебры) появляются сами, а инструментом **«Переход»** их можно поставить **где угодно** (снос — инструментом сноса). Сверху слева — флаг, название, площадь, счётчик.

Горячие клавиши: рисование — **Enter** готово, **Backspace** отменить точку, **Esc**
отмена; выделение — **Delete** удалить, **Esc** снять; **Ctrl+Z** откат, **Ctrl+C/V**
копировать/вставить, **Ctrl+S** сохранить в файл.

**Авто-застройка.** Клик по дороге **без выбранного инструмента** открывает меню:
- *Авто-застройка вдоль дороги* — подсвечиваются сегменты **всех** дорог; клик по участку
  циклит **сторону застройки** (обе → лево → право → выкл), в баре выбираешь **зону**
  (жилая / без магазинов / торговая) → **ОК**. Постройки появятся на чуть разном расстоянии
  (не впритык), входом к дороге, с тропинками; на дорогу не ставятся;
- *Подтянуть здания к дороге* — двигает существующие здания ближе к ближайшей дороге.

**Движение (как в Cities: Skylines).** Кнопка «Движение» в тулбаре запускает симуляцию на
отдельном canvas-слое: **машины** ездят по дорожной сети (по правой полосе, поворачивают на
перекрёстках, **стоят на красный** светофор), **жители** ходят по тропинкам к своим целям.
Включается/выключается одной кнопкой; на редактирование не влияет (агенты эфемерны, не сохраняются).

**Жители.** Каждый пешеход — это **житель** с именем, возрастом и профессией, который
**направляется к зданию** (дом/магазин). Житель получает **дом** и, если в магазинах
есть свободные места, **работу**; занятой ходит по маршруту дом ↔ работа, безработный
бродит по магазинам и домам. **Клик по жителю** (при включённом движении) — **камера
следует** за ним, а сбоку открывается **карточка** с его данными, статусом, целью,
домом, работой и занятостью; клик по пустому месту снимает выбор. *Дальше по плану:
посадка/высадка из машин, построение маршрута по клику.*

> Сохранение двойное: **автосейв** в `localStorage` (постоянно) + ручной **экспорт/импорт**
> в файл — чтобы перенести город или не потерять при чистке браузера.

## Стек

- **Leaflet 1.9.4** — единственная внешняя библиотека, лежит локально в
  `static/vendor/` (без CDN, работает без интернета для карты — тайлы
  спутника всё равно тянутся из сети).
- **FastAPI + uvicorn + SQLite** — бэкенд общего мира (`server.py`).
- Рисование границ/дорог — на ванильном Leaflet, без плагинов.
- Площадь — сферическая формула полигона (без turf.js).
- Тема и SVG-иконки — в стиле GhostEcos (`#D97757`, чёрные панели).

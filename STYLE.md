# Стандарт кода GhostEcos

Действует для всех репозиториев проекта. Новый код — по стандарту; при правках
старого кода стандарт применяется к затронутым участкам, нетронутое не
переформатируется.

## 1. Общие правила (все языки)

- Комментарии — **только по-русски**.
- Комментарий объясняет **почему**, а не что: перед `user = get_user(...)` не пишем `# получаем юзера`.
- Коротко: одна строка — одна мысль. Растянутые комментарии на 2–3 строки запрещены.
- Разделители секций — единый шаблон:
  ```python
  # ── Название секции ──────────────────────────────
  ```
- Без КАПСА. Названия секций и функций — обычный регистр («Получение токена», не «ПОЛУЧЕНИЕ ТОКЕНА»).
  Редкий акцент — префикс в начале строки: `# ВАЖНО:`, `# SECURITY:`, `# TODO:` — единственный допустимый КАПС.
- Emoji в коде — только как функциональная легенда (например, пороги моделей 👑🟢🟡🔴, попутно выводимые в UI), не для украшения.
- Закомментированный код не хранить — удалять (история есть в git).
- Магические числа — в именованные константы с коротким русским комментарием.

## 2. Python (бекенд: FastAPI, uvicorn, SQLite)

- Отступ — 4 пробела, табов нет.
- Длина строки — до **100 символов**; превышение допустимо максимум на **10** (до 110), только когда перенос ухудшает читаемость.
- 2 пустые строки между функциями/классами верхнего уровня, 1 — между методами.
- Пробелы: вокруг операторов, после запятых; без пробела перед скобкой вызова — `func(x)`, не `func (x)`.
- Кавычки — двойные `"..."`.
- f-строки для интерполяции; `%` и `.format` не использовать.

### Именование
- `snake_case` — функции, переменные, модули.
- `_snake_case` — приватное внутри модуля.
- `PascalCase` — классы.
- `UPPER_SNAKE` — константы.
- Без транслита и однобуквенных имён (кроме счётчиков циклов).

### Импорты
Стандартная библиотека → сторонние → свои, группы разделены пустой строкой:
```python
import asyncio
import json

from fastapi import APIRouter

from db import get_db
```

### Типизация
- Сигнатуры публичных функций — с типами.
- `X | None` вместо `Optional[X]`.
- Сложные структуры — `TypeAlias` рядом с использованием.

### Комментарии и docstring
- Комментарии — по разделу 1.
- Docstring — одна короткая русская строка-суть; у очевидных функций — отсутствует:
  ```python
  def _safe_answer_callback(...) -> bool:
      """Не прерываем чужие действия на устаревшем колбэке Telegram."""
  ```
- Аргументы/возвраты в docstring не описывать, если типы и сигнатура говорят сами за себя.
  Развёрнутое «почему» — в `#`-комментарий внутри функции.

### FastAPI-специфика
- Роутеры через `APIRouter`: один домен — один роутер.
- `async def` для всего, что ходит в сеть или БД.
- Ошибки — `raise HTTPException`; тексты/коды ошибок — в константах.

## 3. JavaScript (фронт: vanilla JS + PWA)

- Отступ — **2 пробела**.
- Точка с запятой — всегда.
- Кавычки — одинарные `'...'`; шаблоны — `` `...` ``.
- `const` по умолчанию, `let` только при переприсваивании, `var` запрещён.
- Стрелочные функции по умолчанию; `function` — для hoisted-объявлений верхнего уровня.
- `async/await` вместо цепочек `.then`.

### Именование
- `camelCase` — функции, переменные.
- `PascalCase` — классы, компоненты, конструкторы.
- `UPPER_SNAKE` — константы модуля.
- CSS-классы — `kebab-case`.

### Комментарии
- По разделу 1. Публичная функция — короткая однострочная JSDoc по-русски:
  ```js
  /** Обновляет бейдж непрочитанных в шапке чата. */
  function updateUnreadBadge(count) { ... }
  ```
- DOM: не смешивать поиск элементов и логику; элементы кэшировать в переменные при повторном использовании.

## 4. Dart / Flutter (мобильная часть)

- Форматирование — только `dart format`, руками отступы не править.
- Отступ — 2 пробела (обеспечивает форматтер).
- Кавычки — одинарные `'...'`.
- `const`-конструкторы — везде, где возможно.

### Именование
- `lowerCamelCase` — функции, переменные, именованные параметры.
- `PascalCase` — классы, виджеты, enum'ы.
- Файлы и библиотеки — `snake_case` с подчёркиваниями.

### Структура виджетов
- `build`-методы короткие; поддерево больше ~30 строк — отдельный виджет.
- Повторяющиеся блоки — свои виджеты, не копипаста.

### Комментарии
- По разделу 1. Doc-комментарий `///` — одна русская строка-суть для публичных классов и неочевидных функций:
  ```dart
  /// Экран каталога расширений GhostGallery.
  class GhostGalleryScreen extends StatefulWidget { ... }
  ```

## 5. Коммиты

- Сообщения коммитов — по-русски, коротко: `факт: добавлен каталог расширений`.
- Существующую историю не переписывать.

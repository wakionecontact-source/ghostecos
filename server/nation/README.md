# GhostNation 🛰️ (рабочее название)

Мини-игра экосистемы GhostEcos: основай **своё государство** на реальной
спутниковой карте. Рисуешь свободные границы, ставишь дома / дороги / деревья,
игра считает площадь. Личная песочница — всё хранится локально в браузере
(`localStorage`), без бэкенда.

## Запуск (localhost)

Нужен любой статический http-сервер (через `file://` не заработает — иконки
тянутся через `fetch`). Проще всего Python:

```powershell
cd C:\Users\Home\GE\server\nation\frontend\static
python -m http.server 5500
```

Открыть → http://localhost:5500

> Карта тянет спутник с **Esri World Imagery** (без API-ключа). Если в твоём
> регионе он тупит — переключи слой на **Google** (кнопка снизу справа).
> Leaflet грузится с CDN (unpkg) — нужен доступ в интернет / туннель.

## Управление

Панель инструментов слева:

| Инструмент | Что делает |
|-----------|-----------|
| **Границы**   | кликай по карте — ставишь точки контура страны, «Готово» замыкает |
| **Дом**       | жилой дом — **вальмовая зелёная крыша** (скаты + конёк, вид сверху), оранжевое **крыльцо** (вход) |
| **Магазин**   | коммерция — **плоская синяя кровля** с парапетом и блоком на крыше, крыльцо |
| **Дорога**    | серый асфальт с жёлтой разметкой; после рисования выбираешь **сторону тротуара** (нет / слева / справа / с обеих); точка рядом **примагничивается** |
| **Переулок**  | узкая дорога без разметки и тротуаров; снапится к дорогам/переулкам |
| **Жд**        | насыпь + шпалы + два рельса; тоже с примагничиванием |
| **Тропинка**  | пешая дорожка 1 м, сплошная серая — ложится **бордюром вдоль дороги** (под асфальтом) и соединяется с другими тропинками |
| **Дерево**    | клик сажает дерево (зелёная крона) |
| **Район**     | зона внутри границ страны (рисуешь полигоном; только внутри границ) |
| **Светофор**  | ставится только на **перекрёстке** (снап к пересечению дорог); снос инструментом сноса |
| **Переход**   | пешеходный переход (зебра) **где угодно** — клик по дороге кладёт его поперёк в этой точке (снап к дороге ≤25 м), вдали от дорог ставится свободно; снос инструментом сноса |
| **Изменить**  | клик по постройке → ручки на карте: **двигать / крутить / менять размер**, панель сворачивается |
| **Снести**    | клик по объекту удаляет его; у **дороги/тропинки удаляется только сегмент** под курсором |
| **Отмена**    | откат последнего действия (**Ctrl+Z** или кнопка-стрелка) |
| **Сохранить** | скачать государство в `.json` (**Ctrl+S**) |
| **Загрузить** | восстановить страну из `.json` |
| **Прицел**    | центрирует карту на твоей стране |

Постройки — это **footprint'ы на земле** в метрах, масштабируются вместе с картой. При
установке дом/магазин **поворачивается к ближайшей дороге входом (крыльцом) к ней** и
получает случайный размер (до 30 м на сторону); если задевает соседей — ужимается, а если
точка попала в существующее здание — переносится в свободное место. Через **Изменить** любую постройку
можно подвинуть, повернуть и отресайзить (дом/магазин 1–100 м, дерево радиус 1–50 м), а
также **скопировать/вставить** (Ctrl+C / Ctrl+V). При наведении объект подсвечивается
(в режиме сноса — красным). Дороги и жд единой ширины (7 м); где **дорога пересекает жд —
авто-переезд**, повёрнутый вдоль дороги; на пересечении дорог — **пешеходные переходы** (зебры) появляются сами, а инструментом **«Переход»** их можно поставить **где угодно** (снос — инструментом сноса). Сверху слева — флаг, название, площадь, счётчик.

Горячие клавиши: рисование — **Enter** готово, **Backspace** отменить точку, **Esc**
отмена; выделение — **Delete** удалить, **Esc** снять; **Ctrl+Z** откат, **Ctrl+C/V**
копировать/вставить, **Ctrl+S** сохранить в файл.

**Авто-застройка.** Клик по дороге **без выбранного инструмента** открывает меню:
- *Авто-застройка вдоль дороги* — подсвечиваются сегменты **всех** дорог; клик по участку
  циклит **сторону застройки** (обе → лево → право → выкл), в баре выбираешь **зону**
  (жилая / без магазинов / торговая) → **ОК**. Постройки появятся на чуть разном расстоянии
  (не впритык), входом к дороге, с тропинками; на дорогу не ставятся;
- *Подтянуть здания к дороге* — двигает существующие здания ближе к ближайшей дороге.

**Движение (как в Cities: Skylines).** Кнопка «Движение» в тулбаре запускает симуляцию на
отдельном canvas-слое: **машины** ездят по дорожной сети (по правой полосе, поворачивают на
перекрёстках, **стоят на красный** светофор), **жители** ходят по тропинкам к своим целям.
Включается/выключается одной кнопкой; на редактирование не влияет (агенты эфемерны, не сохраняются).

**Жители.** Каждый пешеход — это **житель** с именем, возрастом и профессией, который
**направляется к зданию** (дом/магазин). **Клик по жителю** (при включённом движении) — **камера
следует** за ним, а сбоку открывается **карточка** с его данными, статусом и целью; клик по
пустому месту снимает выбор. *Дальше по плану: посадка/высадка из машин, построение маршрута по клику.*

> Сохранение двойное: **автосейв** в `localStorage` (постоянно) + ручной **экспорт/импорт**
> в файл — чтобы перенести город или не потерять при чистке браузера.

## Стек

- **Leaflet** (единственная внешняя зависимость, с CDN) — карта и слои.
- Рисование границ/дорог — на ванильном Leaflet, без плагинов.
- Площадь — сферическая формула полигона (без turf.js).
- Тема и SVG-иконки — в стиле GhostEcos (`#D97757`, чёрные панели).

## Дальше по плану (не вошло)

- Экономика на `gost`: застройка стоит ресурсы, налоги с площади.
- Ещё типы построек (фермы, заводы, столица); прокладка дорог по кривой.
- Бэкенд (`server.py` рядом, как у `social`) → сохранение на сервере, общий мир.
- Скриншот-открытка страны для шаринга в канал.

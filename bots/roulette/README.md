# GhostRoulette · каркас бота

Минимальный шаблон Telegram-бота с **интегрированной admin-панелью** в браузере.
Текущий статус: **каркас**, бизнес-логика рулетки добавляется отдельно.

## Что внутри

- **bot.py** — точка входа. Запускает aiogram-бот (через прокси) + FastAPI с UI.
- **admin/index.html** — браузерная панель: статы, real-time логи, кнопки команд, консоль.
- **start.bat** — двойной клик → venv создаётся → ставятся зависимости → запуск.

## Первый запуск (Windows)

1. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/) — обязательно с галочкой «Add Python to PATH».
2. Запусти **V2RayTun**, проверь что включен SOCKS прокси (по умолчанию порт `10808`).
3. Получи токен у **@BotFather** в Telegram.
4. Двойной клик по **start.bat**.
5. При первом запуске откроется `.env` в блокноте — впиши:
   - `BOT_TOKEN` — твой токен
   - `PROXY_URL` — оставь по умолчанию или поменяй порт если у тебя другой
   - `ADMIN_USER_ID` — твой Telegram ID (получишь у бота через `/id` после первого запуска)
6. Сохрани, запусти `start.bat` снова.
7. Откроется браузер с admin-панелью на `http://127.0.0.1:8088`.

## Что в админке

- **Статистика** — uptime, юзеры, сообщения, команды
- **Команды** — кнопки + текстовая консоль:
  - `ping` — проверка коннекта к Telegram
  - `stats` — JSON-снапшот
  - `broadcast <текст>` — рассылка всем виденным юзерам
  - `clearlogs` — очистить лог-буфер
  - `stop` — graceful shutdown
  - `help` — список
- **Логи** — live-стрим через WebSocket, цветной по уровням

## Добавить новую команду

В `bot.py`:
```python
@admin_command("mycmd", "Описание для UI", button=True)
async def cmd_admin_mycmd(args: list[str]) -> str:
    return "результат"
```
Она автоматически появится в кнопках админки и в `help`.

## Если что-то не работает

- **Бот не запускается, "Network is unreachable"** → V2RayTun не запущен или порт другой. Проверь в V2RayTun: Settings → Inbounds → SOCKS port. Подставь в `PROXY_URL`.
- **`ImportError aiogram`** → удали папку `venv`, запусти `start.bat` заново.
- **Admin-панель не открылась** → открой вручную `http://127.0.0.1:8088/`.
- **WebSocket не коннектится** → проверь что FastAPI поднялся (в логах cmd-окна должно быть `Admin UI: http://127.0.0.1:8088`).
